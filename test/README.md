# Test

Questa cartella contiene prove, fixture, risultati attesi e materiali temporanei
usati per verificare il progetto.

- Separa le fixture riproducibili dagli artefatti eliminabili.
- Mantieni i test indipendenti dai dati personali o riservati non necessari.
- Documenta i prerequisiti quando una prova non può essere eseguita direttamente.
- Non usare i risultati dei test come input del lavoro ordinario.
