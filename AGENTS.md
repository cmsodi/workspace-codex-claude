# Istruzioni per Codex

## Parte specifica di Codex

- Le skill locali sono in `.agents/skills/`; usa quella più specifica per la
  richiesta corrente.
- La directory fisica condivisa è `.agents/`; `.claude` è soltanto un
  collegamento simbolico alla stessa directory.
- Nei file e nei percorsi operativi usa sempre la forma canonica
  `.agents/...`.

## Parte comune

Prima di operare, leggi per intero `PROJECT_GUIDE.md` nella radice del
progetto e applicane le istruzioni.
