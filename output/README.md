# Output

Questa cartella raccoglie prodotti generati, esportazioni e materiali destinati
all'ispezione o alla consegna.

- Non usarla come fonte operativa corrente, salvo indicazione esplicita in
  `PROJECT_GUIDE.md`.
- Mantieni riconoscibili formato, versione e stato di approvazione.
- Conserva in `lavorazione/` gli intermedi necessari a rigenerare il prodotto.
- Registra i controlli eseguiti prima della consegna.
