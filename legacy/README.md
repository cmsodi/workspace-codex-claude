# Legacy

Questa cartella conserva materiali superati o trasferiti per memoria storica,
recupero e confronto.

- Preferisci l'archiviazione alla cancellazione quando il materiale può essere
  utile per ricostruire decisioni o procedure.
- Indica, quando necessario, provenienza e motivo del trasferimento.
- Non considerare questi file come fonti operative correnti.
- Consulta `legacy/` soltanto quando il compito richiede espressamente un
  recupero, un confronto o una ricostruzione storica.
