# Input

Questa cartella accoglie i materiali ricevuti o messi a disposizione del
progetto: documenti sorgente, dati, allegati e contenuti da elaborare.

- Conserva inalterati gli originali, salvo richiesta esplicita.
- Registra provenienza, data e versione quando non risultano già evidenti.
- Colloca trasformazioni, estrazioni e bozze in `lavorazione/`.
- Indica in `PROJECT_GUIDE.md` quali input sono correnti e quale ordine di
  autorità seguire in caso di divergenza.
